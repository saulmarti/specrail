# SpecRail branding directions

## Positioning

**Category:** delivery governance for coding agents  
**Core promise:** turn agent output into human-approved, evidence-backed software delivery.  
**Personality:** calm, rigorous, modern, trustworthy, developer-native.  
**Avoid:** robot heads, brains, magic sparkles, generic AI gradients, or enterprise bureaucracy.

## Recommended verbal identity

Primary tagline:

> **Human-approved, evidence-backed software delivery for coding agents.**

Short alternatives:

- **Put software agents on rails.**
- **From prompt to proven delivery.**
- **Ship agent-written code with evidence.**
- **The approval and evidence layer for Codex.**

Recommended homepage headline:

> **Your coding agent can write the code. SpecRail makes the delivery trustworthy.**

## Logo concepts

### A. The S Rail — recommended

Two parallel rails bend into a minimal `S`. A small checkpoint or signal dot represents human approval. It works as a favicon and npm avatar without needing text.

### B. Spec on Track

A minimal document corner whose two lower lines continue as railway tracks. Communicates specification plus controlled delivery, but is slightly more literal.

### C. Gate and Check

A single rail passes through a compact gate/checkpoint. Strong governance meaning, but should remain simple enough not to resemble transport software.

### D. Trace Line

A continuous line connects four nodes representing taskset, harness, runtime, and trace. More technical and suitable for diagrams, but weaker as a small commercial icon.

## Color directions

### Graphite + Signal Green — recommended

- Graphite: `#17191C`
- Soft surface: `#F4F5F2`
- Signal green: `#39D98A`
- Muted steel: `#707780`

Feels technical and trustworthy; green communicates passed gates without looking like generic neon AI.

### Deep Navy + Amber

- Navy: `#111B2E`
- Warm white: `#FAF8F3`
- Signal amber: `#F2A93B`

More product/enterprise-oriented and suitable if governance becomes the dominant message.

### Ink + Electric Violet

- Ink: `#17151E`
- Pale gray: `#F5F3F7`
- Violet: `#7867F2`

More modern and AI-adjacent, but less differentiated from developer-tool competitors.

## Typography

- Interface and marketing: **Geist**, **Inter**, or system sans.
- Code and evidence labels: **Geist Mono**, **IBM Plex Mono**, or system monospace.
- Prefer medium weights, clear hierarchy, and compact evidence labels over oversized marketing typography.

## Visual language

- Rails, gates, checkpoints, linked evidence, and signed traces.
- Calm diagrams with one accent color.
- Real product screenshots and before/proposal/after comparisons.
- Status words paired with icons; never rely only on color.
- Minimal motion that communicates progression or gate transitions.

## Naming architecture

- **SpecRail Core** — CLI, skills, gates, and repository artifacts.
- **SpecRail Cockpit** — local review experience.
- **SpecRail Replay** — replayable tasksets and harness comparison.
- **SpecRail Doctor** — onboarding and environment repair.
- **SpecRail Policies** — future constitution/evidence packs.

## Recommended first brand package

1. S Rail icon.
2. Graphite + Signal Green palette.
3. Geist/Geist Mono typography.
4. README hero with the workflow rail diagram.
5. One short animated demo: request → approved spec → evidence → merge.
