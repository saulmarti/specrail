# AI Flow 0.3 Design

## Goal

Improve delivery quality and total cycle time without adding agents or forcing extra user interactions.

## Deterministic additions

1. **Specification approval hash**: hash the user-approved specification and invalidate approval when any governed field changes.
2. **Lightweight task lease**: one active Codex session owns execution at a time; leases expire and can be taken over through native input.
3. **Specification linter**: reject incomplete, vague, or non-observable specifications before user review.
4. **Review bundles**: generate one compact Markdown artifact for specification and final review, with embedded relative evidence links.
5. **Progressive context budgets**: give each task a small initial context allowance, permit justified read-only expansions, and require user approval only beyond safe limits.

## Non-goals

- No new agents.
- No CodeGraph wrapper.
- No mandatory repository-wide scan.
- No remote service or database.
- No extra user approval for safe read-only context expansion.
