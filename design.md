# SpecRail Design System

## Selected logo direction
Chosen concept: **Guided Path / Checkpoint** (the 3rd exploration).

This mark represents:
- two parallel rails = process, structure, repeatability;
- a centered checkpoint = human approval, verification, control;
- a minimal circular interrupt = decision gate without visual noise.

The logo is intentionally simple, geometric, and technical.

## Core brand attributes
- Precise
- Trustworthy
- Technical
- Premium
- Minimal
- Calm, not flashy

## Color palette
- **Graphite**: `#17191C`
- **Signal Green**: `#39D98A`
- **Soft Surface**: `#F4F5F2`
- **Muted Steel**: `#707780`
- **White**: `#FFFFFF`

## Typography
Recommended:
- **Primary UI / marketing**: Geist, Inter, or a clean neo-grotesk sans serif
- **Monospace / technical examples**: Geist Mono, JetBrains Mono, or IBM Plex Mono

## Logo usage
### Primary
Use `specrail-wordmark-primary` on light backgrounds.

### Dark usage
Use `specrail-wordmark-dark` on graphite or dark UI.

### Monochrome
Use monochrome variants when color reproduction is limited.

### App icon / favicon
Use `specrail-icon-primary` or `specrail-icon-dark`.

## Spacing and clear space
Minimum clear space around the logo: at least the radius of the central ring.

## Minimum sizes
- Favicon / small app icon: 20 px+
- Nav logo: 28 px icon height
- Wordmark in landing hero: 40–56 px icon height

## Do not
- Do not stretch the logo.
- Do not rotate the symbol.
- Do not replace the circle with another decorative shape.
- Do not add gradients or shadows in product UI.
- Do not use neon or highly saturated colors beyond Signal Green.

## UI direction
### Surfaces
- Light default background using Soft Surface or white.
- Dark product areas can use Graphite.
- Signal Green should be used as an accent, not as a full background.

### Components
- Rounded but not playful.
- Clear hierarchy.
- Dense enough for advanced users.
- Favor evidence, metrics, code blocks, and structured states.

## Messaging tone
SpecRail should sound:
- direct,
- technical,
- confident,
- evidence-driven,
- non-hype.

Avoid generic AI-marketing language.
