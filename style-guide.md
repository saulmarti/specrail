# SpecRail Style Guide

## 1. Brand foundation
SpecRail is the approval and evidence layer for coding agents. Its visual identity should communicate **control, clarity, and trustworthy technical rigor**.

## 2. Logo
The approved logo is a minimal **guided path / checkpoint** mark.

### Symbol meaning
- Horizontal rails = direction and controlled delivery
- Central ring = approval / checkpoint / proof gate
- Symmetry = deterministic workflow

## 3. Colors
| Token | Hex | Usage |
|---|---|---|
| Graphite | #17191C | Primary text, dark UI, icon lines |
| Signal Green | #39D98A | Accent, approval state, highlight |
| Soft Surface | #F4F5F2 | Default page background |
| Muted Steel | #707780 | Secondary text |
| White | #FFFFFF | Contrast on dark surfaces |

## 4. Typography
- Headlines: Geist / Inter / SF Pro Display equivalent
- Body: Geist / Inter / system sans
- Code / metrics: Geist Mono / JetBrains Mono

## 5. UI style principles
- Minimal but not empty
- Technical but not intimidating
- Premium through spacing and restraint
- Color used sparingly
- Dense enough for advanced users

## 6. Layout principles
- Strong grid
- Clear section rhythm
- Compact cards for metrics and evidence
- Avoid decorative clutter

## 7. Iconography
Use line-based icons with rounded caps and moderate stroke width.

## 8. Imagery
Favor:
- product UI,
- evidence views,
- diff comparisons,
- technical diagrams,
- traces and metrics.

Avoid stock photography.
